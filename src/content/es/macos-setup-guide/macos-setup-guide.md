Configurar una nueva máquina de desarrollo puede ser una tarea abrumadora. Esta serie busca convertir ese proceso en un flujo rápido, reproducible y documentado. Desde la automatización del sistema base hasta la personalización avanzada de la shell y la infraestructura como código para tus dotfiles, esta guía cubre todo lo que necesitas para construir una workstation premium para desarrollo.

> [!TIP]
> **¿Ya tienes tus dotfiles listas?**
> Si ya has seguido esta guía una vez y sólo necesitas preparar un Mac completamente nuevo, salta directamente a [Configurar un Mac nuevo con un solo comando](/es/docs/macos-setup-guide/dotfiles-and-reproducibility#5-setting-up-a-new-mac-in-one-command).

## Los fundamentos

1. **[Automatizar la configuración de macOS: Homebrew, Brewfile y herramientas CLI esenciales](/es/docs/macos-setup-guide/base-system-setup-macos)**
   La base de cualquier entorno moderno en macOS. Aprende a usar Homebrew para gestionar todo tu sistema como código.

2. **[Elegir y configurar el mejor terminal para macOS: Ghostty vs iTerm2](/es/docs/macos-setup-guide/terminal-setup-macos)**
   Tu terminal es tu hogar. Comparamos las opciones modernas más rápidas y las configuramos para obtener el mejor rendimiento.

3. **[Asegurar tu identidad: claves SSH, GPG y 1Password en macOS](/es/docs/macos-setup-guide/ssh-and-authentication)**
   La seguridad no debería ser un obstáculo. Integra 1Password con SSH y GPG para un flujo seguro y sin fricción.

## Productividad y flujo de trabajo

4. **[Configuración avanzada de Git: productividad, seguridad e ignores globales](/es/docs/macos-setup-guide/git-and-version-control)**
   Ve más allá de `git commit`. Configura paginadores como Delta, alias y hooks globales.

5. **[El toolkit moderno de DevOps: herramientas CLI esenciales para macOS](/es/docs/macos-setup-guide/shell-cli-tooling)**
   Una selección de reemplazos modernos para herramientas Unix clásicas (`ripgrep`, `fd`, `bat` y más).

6. **[Mejorar la usabilidad de la shell: FZF, autocompletado en Zsh y configuración modular](/es/docs/macos-setup-guide/shell-usability-improvements)**
   Haz que tu shell se sienta viva con búsqueda difusa y autocompletado inteligente.

7. **[Construir el prompt definitivo con Starship: rápido y contextual](/es/docs/macos-setup-guide/prompt-and-ux)**
   El único prompt que vas a necesitar. Minimalista, rápido y compatible con varias shells.

## Entorno y tooling

8. **[Gestionar secretos y entornos en macOS: 1Password CLI y Direnv](/es/docs/macos-setup-guide/secrets-and-environment-management)**
   Automatiza variables de entorno según el directorio actual sin filtrar secretos.

9. **[Desarrollo moderno con Python en macOS: rápido y aislado con UV](/es/docs/macos-setup-guide/python-and-automation-tooling)**
   Olvida `pip` y `conda`. Aprende cómo `uv` hace que el desarrollo en Python sea instantáneo y reproducible.

10. **[El toolkit del ingeniero cloud-native: Kubernetes, Terraform y Helm en macOS](/es/docs/macos-setup-guide/kubernetes-and-devops-tooling)**
    Configura lo esencial para infraestructura cloud y orquestación de contenedores.

## Configuración avanzada

11. **[La configuración definitiva de Neovim para ingenieros DevOps: velocidad y precisión](/es/docs/macos-setup-guide/editor-setup-neovim)**
    Un análisis a fondo de por qué Neovim es el editor ideal para ingeniería de alto rendimiento.

12. **[Infraestructura como código para tu Mac: gestionar dotfiles con Chezmoi](/es/docs/macos-setup-guide/dotfiles-and-reproducibility)**
    La última pieza del puzzle. Sincroniza toda tu configuración entre máquinas con Git y Chezmoi.
